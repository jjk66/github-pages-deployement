# github-pages-deployement workflow

## Requirements
This is a roadmaps.sh project and can be found here:

https://roadmap.sh/projects/github-actions-deployment-workflow

Create a GitHub action to:
- deploy changes made to the index.html file to GitHub Pages
- use workflows to trigger the action when commits to the main branch for changes to the index.html file
- access the website by using the GitHub pages url for this repository: https://jjk66.github.io/github-pages-deployment/

## Clone the repository to get the tool
```bash
git clone git@github.com:jjk66/github-pages-deployment.git
```
